# Brand Hubs

One file per client, named in lowercase with hyphens: `revive-collagen.md`, `bella-duke.md`.

Each Brand Hub covers:

- Fonts and caption style
- Colours (with hex codes)
- Current packaging and product variants
- CTA and end card, by product and offer
- Music and SFX rules
- Pronunciation and VO locale
- Banned visuals and compliance limits
- Links to the client's Frame.io library and key files

The client overrides at the bottom of `standards/editing-standards.md` are the starting point for each file. When a client's Brand Hub is created, move that client's row across.
