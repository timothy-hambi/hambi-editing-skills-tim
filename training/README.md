# Training

The fortnightly Editing team training sessions, which replace the Monday 12pm BST catch-up.

- `plan.md` holds the rolling topic plan for upcoming sessions (to be added).
- `sessions/` holds one file per session: `YYYY-MM-DD-topic.md`.

Each session file includes the topic, why it was chosen (the gap or feedback trend behind it), the outline, links to any Loom or SOP produced, and follow-ups.
