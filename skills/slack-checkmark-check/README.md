# slack-checkmark-check

**Status:** Live

Checks who has and hasn't reacted with a ✅ check mark on any Slack message, from a pasted Slack message link. Use whenever Tim pastes a Slack message link and asks who has ticked, checked, ✅'d or acknowledged it, e.g. "check mark check on this", "who's ticked this", "who hasn't acknowledged", "run the ✅ check", "who still needs to react", or just pastes a Slack link with "check" or "ticks". Typical uses are allocation posts, handover/handback messages, deadline reminders and announcements during Acting PPM cover. Read-only; never sends anything.

The instructions Claude follows are in `SKILL.md`.
