# ticket-status-checker

**Status:** Live

Checks which of an editor's Client Review tickets have actually been approved. Use when Tim names an editor and wants to know which of their Client Review tickets are approved, e.g. 'check [editor]'s tickets', 'what's approved for [editor]', 'status check on [editor]', 'which of [editor]'s Client Review tickets can move to Approved', 'ticket status checker', or any request to compare an editor's Client Review tickets in Editor Tickets or Editor Capacity against the original client tickets. It only reads and reports and never changes a ticket.

The instructions Claude follows are in `SKILL.md`.
