# iteration-editor

**Status:** Live

Edit an iteration of an already-running ad without Premiere: Notion Iteration Ticket (Iterations table, one row per variation) → find the original → change sheet → approval → FFmpeg render with a lock check that proves nothing else moved → review rounds (Edit Review if installed, otherwise chat) → Premiere XML. Use whenever Tim or an editor shares a ticket named Iteration_…, a ticket with Ad Type Iterations, a 'Link to original', or asks to iterate on, tweak, re-hook, re-VO, re-caption, reorder, re-CTA or add an offer/BFCM angle to a finished or live ad, e.g. 'do this iteration', 'iteration-editor', 'make the V1 and V2 iterations', 'swap the hook on the winning ad', 'just the change sheet for this iteration'. Use this instead of hp-editor-agent or premiere-script-prompt when there is no script table and the job is a few changes to an existing edit.

The instructions Claude follows are in `SKILL.md`.
