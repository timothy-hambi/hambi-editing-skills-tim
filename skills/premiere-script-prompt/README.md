# premiere-script-prompt

**Status:** Live

Turns a Notion editor ticket (script table, hook variations, Frame.io shot links) plus footage transcripts into a timecoded script prompt (cut sheet) for Adobe Premiere Pro via the Premiere MCP, with SRT subtitles and placeholders, then builds it in Premiere only after the user approves that exact version. Script mode: use whenever Tim or an editor shares a Notion ticket, Frame.io links, footage, a transcript or a VO script and wants an initial cut, rough cut, selects, stringout, paper edit, hook variations, an A-roll/B-roll ad, a founder or interview Q&A or an AI-VO mash-up, e.g. \"turn this ticket into a script prompt\", \"cut this\", \"build the edit\"; also for revising, re-approving, adding B-roll, placeholders or subtitles, or running a connector preflight. Execute mode: use when a new chat starts with \"APPROVED vN. Execute from [path to a ScriptPrompt .md]\" to build an approved sheet in Premiere.

The instructions Claude follows are in `SKILL.md`.
