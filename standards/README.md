# Standards

House rules that apply to every HP edit unless the ticket or Brand Hub says otherwise.

- `editing-standards.md` holds the main rulebook: captions, B-roll, pacing, hooks, colour, audio, CTA and compliance, plus the pre-export checklist.

Every rule has an ID (C1, B4, P2 and so on) so feedback and QA notes can reference it directly, for example "see S5".

When you add a rule, give it the next number in its section and add a dated line to the changelog at the bottom of the file.
