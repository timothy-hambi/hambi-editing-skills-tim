# SOPs

Finished Editing team SOPs. These are the drafts or source copies of what gets published in Notion.

- Use one file per SOP, named after the process: `ticket-handoff.md`, `frame-upload.md`.
- Put the Notion link at the top of each file once it's published.
- If the Notion version is edited, update the file here as well so the two don't drift apart.
